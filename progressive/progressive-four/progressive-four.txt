4. Webhook Delivery Tracker

Webhook delivery attempts look like:

[
    {"event_id": "e1", "attempt": 1, "timestamp": 100, "status": 500},
    {"event_id": "e1", "attempt": 2, "timestamp": 110, "status": 200},
    {"event_id": "e2", "attempt": 1, "timestamp": 115, "status": 429}
]

Attempts are in chronological order.

Part 1

Implement:

def delivery_results(attempts):
    ...

For each event, return the number of attempts and whether it eventually succeeded.

Any 2xx status is successful.

Part 2

After an event succeeds, later attempts for that event should be ignored.

Also return the number of ignored attempts.

Part 3

An event is considered stuck if it has not succeeded and its most recent accepted attempt is at least timeout seconds before current_time.

Return all stuck event IDs ordered by the timestamp of their most recent accepted attempt, oldest first.

Break ties by event ID.
